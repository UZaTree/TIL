# 컬럼 연산

> SELECT 시 컬럼에 직접 연산을 적용해 출력 가능

---

## 숫자 사칙연산

```sql
-- 컬럼에 상수 연산
SELECT 사용금액 * 0.9 FROM card;

-- 여러 컬럼 동시에, AS 병행 가능
SELECT 사용금액 * 0.9 AS 부가세제외, 연체횟수 + 100 FROM card;
```

| 연산 | 기호 |
|------|------|
| 덧셈 | `+` |
| 뺄셈 | `-` |
| 곱셈 | `*` |
| 나눗셈 | `/` |

## 컬럼끼리 연산

```sql
-- 결제당 평균 사용금액
SELECT 사용금액 / 결제횟수 FROM card;
```

> 숫자 컬럼에만 적용 가능. 문자 컬럼 연산은 [문자 함수](./string-functions.md) 참고
