# LIKE 패턴 검색

> 특정 문자열이 포함된 행을 검색할 때 사용 — 문자 컬럼에서만 동작

---

## 기본 문법

```sql
SELECT * FROM product
WHERE 상품명 LIKE '%소파%';
```

`컬럼명 LIKE '패턴'` 형식으로 사용. 패턴 없이 `LIKE '소파'` 만 쓰면 정확히 일치하는 행만 찾으므로 의미없음 → 와일드카드 필수

---

## 와일드카드

### % — 글자 수 제한 없는 아무 문자 (0자 포함)

| 패턴 | 의미 | 예시 |
|------|------|------|
| `'%소파%'` | 소파가 포함된 모든 것 | 가죽소파, 소파베드, 패브릭소파 |
| `'소파%'` | 소파로 시작하는 것 | 소파베드, 소파커버 |
| `'%소파'` | 소파로 끝나는 것 | 가죽소파, 패브릭소파 |

### _ — 아무 문자 정확히 1개

```sql
-- '아무글자 2개 + 소파' 형태만 검색
SELECT * FROM product
WHERE 상품명 LIKE '__소파';
```

글자 수까지 정확히 지정해서 검색하고 싶을 때 사용

---

## 주의사항

**성능**: `%`를 앞에 붙이면(`'%소파'`) 인덱스를 활용 못해 속도 저하 발생. `=`, `!=`, `IN ()` 등으로 처리 가능한 경우 LIKE 대신 사용 권장. 자세한 원리는 인덱스 파트에서 정리 예정

**CHAR 타입**: `CHAR(6)`에 `'가죽소파'` 저장 시 실제로는 `'가죽소파  '`(뒷부분 공백 채움)로 저장됨. `'%소파'`로 검색하면 해당 행을 못 찾을 수 있으니 주의
