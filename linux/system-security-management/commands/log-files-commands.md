# 로그 관련 명령어

## 1. last

`last`는 `/var/log/wtmp` 파일을 참조하여 사용자의 로그인 및 로그아웃 기록을 확인하는 명령어이다.

### 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-f` | 지정한 파일을 사용 |
| `-n` | 출력할 행의 개수 지정 |
| `-t` | 지정한 시간 이전의 로그인 기록 출력 |
| `-R` | 호스트 이름을 출력하지 않음 |
| `-a` | 마지막 열에 호스트 이름 출력 |
| `-d` | 원격 로그인 시 IP 주소를 호스트 이름으로 변환 |
| `-F` | 로그인 및 로그아웃 시간을 포함하여 전체 시간 출력 |
| `-i` | IP 주소 형태로 원격 호스트 표시 |
| `-w` | 사용자 이름과 호스트 이름을 모두 표시 |

---

## 2. lastlog

`lastlog`는 각 사용자의 마지막 로그인 정보를 확인하는 명령어이다.

### 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-u` | 특정 사용자의 마지막 로그인 정보 확인 |
| `-t` | 지정한 기간 이내에 로그인한 사용자 표시 |
| `-b` | 지정한 기간 이전에 마지막으로 로그인한 사용자 표시 |

---

## 4. dmesg

`dmesg`는 커널 링 버퍼에 기록된 메시지를 출력하는 명령어이다.

### 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-c` | 출력 후 커널 링 버퍼의 내용을 지움 |

---

## 5. logger

`logger`는 시스템 로그에 메시지를 기록하는 명령어이다.

### 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-i` | 각 로그 메시지에 프로세스 ID를 기록 |
| `-f` | 지정한 파일의 내용을 로그 메시지로 기록 |
| `-t` | 로그에 지정한 태그를 사용 |
| `-s` | 로그 메시지를 표준 오류에도 출력 |
