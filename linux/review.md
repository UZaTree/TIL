# Linux Review

## RE 목록

- `stat` 명령으로 확인할 수 없는 정보
  - `stat`은 파일 및 디렉터리의 메타데이터를 확인한다.
  - 실행 중인 프로세스의 PID는 `stat`으로 확인하지 않는다.

- `mount`와 `umount`
  - `mount`는 파일 시스템을 특정 디렉터리에 연결한다.
  - `umount`는 마운트된 파일 시스템의 연결을 해제한다.

- 하드 링크
  - 하드 링크는 원본 파일과 동일한 inode를 공유한다.
  - 다른 파일 시스템에는 생성할 수 없다.

- 심볼릭 링크
  - 심볼릭 링크는 원본과 다른 inode를 가진다.
  - 다른 파일 시스템에도 생성할 수 있다.
  - 원본 파일을 삭제하면 링크가 끊어진다.

- `/proc/self`
  - 현재 접근 중인 프로세스 자신을 가리키는 특수 경로이다.

- `kill -9`
  - `SIGKILL`을 전달하여 프로세스를 강제 종료한다.
  - `SIGKILL`은 프로세스가 무시하거나 처리할 수 없다.

- 기타 사용자(Other)
  - 파일의 소유자도 아니고 해당 파일의 그룹에도 속하지 않는 사용자이다.

- `umask`
  - 새로 생성되는 파일과 디렉터리의 기본 권한에서 제한할 권한을 지정한다.
  - `umask 022`이면 일반 파일은 `644`, 디렉터리는 `755`가 된다.

- `sed -n '5p'`
  - `-n`은 기본 출력을 억제한다.
  - `p`는 지정한 줄을 출력한다.
  - 따라서 5번째 줄만 출력한다.

- 확장 정규 표현식(ERE)
  - `egrep`은 확장 정규 표현식을 사용한다.
  - `|`와 같은 메타문자를 사용할 수 있다.

  - `su -` 완전 전환
  - `su -`는 로그인 셸로 전환하여 대상 사용자의 환경을 새로 적용한다.
  - `su`는 기본적으로 현재 사용자의 환경을 유지하면서 사용자만 전환한다.
  - `su jiwon`은 사용자 `jiwon`으로 전환하면서 현재 환경 변수를 유지하는 형태이다.

- `whoami`와 `logname`의 차이
  - `whoami`는 현재 유효 사용자(Effective User)를 출력한다.
  - `logname`은 로그인한 사용자를 출력한다.

- `/etc/default/useradd`와 `/etc/login.defs`
  - `/etc/default/useradd`는 `useradd` 명령의 기본 설정을 관리한다.
  - `/etc/login.defs`는 사용자 및 로그인 관련 기본 정책을 관리한다.

- `tail -f`
  - 파일의 마지막 부분을 출력한 뒤 파일에 추가되는 내용을 실시간으로 계속 확인한다.

- 런레벨
  - 런레벨 숫자별 의미를 구분한다.
  - `0`: 종료
  - `1`: 단일 사용자 모드
  - `3`: 다중 사용자 텍스트 모드
  - `5`: 다중 사용자 그래픽 모드
  - `6`: 재부팅

- `usermod`의 `-l`과 `-L`
  - `-l`: 사용자 로그인 이름 변경
  - `-L`: 사용자 계정 잠금

- `lslogins`
  - `-u`: 사용자 계정 정보 출력
  - `-L`: 로그인 관련 정보 출력

- `grep`과 `egrep`
  - `grep`은 기본 정규 표현식(BRE)을 사용한다.
  - `egrep`은 확장 정규 표현식(ERE)을 사용한다.
  - ERE에서는 `|`를 사용하여 OR 조건을 표현할 수 있다.

- `useradd -d`
  - 사용자의 홈 디렉터리를 지정한다.

- `userdel -r`
  - 사용자 계정을 삭제하면서 해당 사용자의 홈 디렉터리와 메일 스풀도 삭제한다.

- Set-UID
  - 실행 파일에 Set-UID가 설정되면 실행 시 파일 소유자의 권한으로 동작한다.
  - `suid`는 Set-UID를 의미한다.

- `chmod g+s /project`
  - `/project` 디렉터리에 Set-GID를 설정한다.
  - 해당 디렉터리에서 생성되는 파일과 디렉터리는 디렉터리의 그룹을 상속받는다.

- Sticky-Bit
  - 디렉터리에 Sticky-Bit가 설정되면 해당 디렉터리의 파일을 삭제할 수 있는 사용자가 제한된다.
  - 일반적으로 파일 소유자, 디렉터리 소유자, root만 삭제할 수 있다.

- `$6$`
  - `/etc/shadow`의 암호 해시에서 `$6$`은 SHA-512 기반 암호 해시 알고리즘을 의미한다.

- `mount -a`
  - `/etc/fstab`에 등록된 파일 시스템 중 `noauto`가 아닌 항목을 마운트한다.

- ext와 XFS
  - ext 계열 파일 시스템은 Debian 계열에서 주로 사용된다.
  - XFS는 Red Hat 계열에서 주요 파일 시스템으로 사용된다.

- MSDOS와 GPT
  - `msdos`는 MBR 파티션 테이블을 의미한다.
  - `gpt`는 GPT 파티션 테이블을 의미한다.

- `/etc/fstab` 6개 필드
  - 장치 → 마운트포인트 → 파일시스템 → 옵션 → 덤프 → 검사순서

- `defaults`
  - `defaults`에는 `auto`가 포함된다.
  - 따라서 일반적으로 `defaults`가 지정된 fstab 항목은 부팅 시 자동 마운트된다.

- `udevadm settle`
  - udev 이벤트 처리가 완료될 때까지 기다린다.

- `ls -il`
  - `-i`는 inode 번호를 출력한다.
  - `-l`은 상세 정보를 출력한다.
  - 따라서 inode 번호와 상세 정보를 함께 확인할 수 있다.

- `ls -lh`
  - `-h`는 파일 크기를 사람이 읽기 쉬운 단위로 표시한다.
  - 상세 정보까지 확인하려면 `-l`과 함께 사용한다.

- `ls -Z`
  - SELinux 보안 컨텍스트를 출력한다.
  - SELinux 관련 옵션은 대문자 `-Z`이다.

- 장치 장착 후 작업 순서
  - 새로운 장치를 인식시킨 뒤 파티션 작업을 수행한다.
  - 파티션 테이블 변경 후 `partprobe` 등을 이용하여 커널에 변경 사항을 반영할 수 있다.
  - udev 장치 생성이 필요한 경우 `udevadm settle`로 처리가 완료될 때까지 기다릴 수 있다.
  - 이후 파일 시스템 생성, 마운트포인트 생성, 마운트 등의 작업을 수행한다.
  - 재부팅이 필요한 경우와 `partprobe`로 즉시 반영할 수 있는 경우를 구분한다.

- `parted`와 GPT
  - `parted`는 파티션을 관리하는 명령어이다.
  - `gpt`는 파티션 테이블의 종류이다.

- `partprobe`
  - 파티션 테이블의 변경 사항을 커널에 알린다.

- 스왑 파일 생성 순서
  - `dd` 등으로 스왑 파일을 생성한다.
  - 필요에 따라 `chmod 600`으로 권한을 제한한다.
  - `mkswap`으로 스왑 영역을 만든다.
  - `swapon`으로 스왑을 활성화한다.

- `swapon -s`
  - 현재 활성화된 스왑 영역의 사용 현황을 출력한다.

- `blkid -L`
  - 파일 시스템의 LABEL을 이용하여 해당 장치명을 출력한다.
