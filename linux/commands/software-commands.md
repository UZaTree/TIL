## RPM

RPM(Red Hat Package Manager)은 RPM 패키지를 설치하고 관리하는 패키지 관리 도구이다.

### 기본 사용법

rpm [option] [패키지_파일명]

RPM의 주요 기능은 다음 5가지 모드로 구분한다.

| 모드 | 설명 |
|---|---|
| 설치 및 갱신 | 패키지를 설치하거나 기존 패키지를 갱신 |
| 제거 | 설치된 패키지를 삭제 |
| 질의 | 패키지의 정보 및 설치 상태 등을 확인 |
| 검증 | 설치된 패키지의 파일 상태를 검증 |
| 리빌드 | 소스 RPM(`.src.rpm`)을 바이너리 RPM으로 재빌드 |

### 설치 및 갱신 모드

| 옵션 | 설명 |
|---|---|
| `-i` | 패키지 설치 |
| `-U` | 패키지 갱신. 기존 패키지가 없으면 설치 |
| `-F` | 패키지 갱신. 기존 패키지가 설치되어 있는 경우에만 갱신 |
| `-v` | 자세한 정보 출력 |
| `-h` | 설치 진행 상황을 `#`으로 표시 |
| `--force` | 기존 파일이나 패키지가 있어도 강제로 설치 |
| `--nodeps` | 의존성 검사를 하지 않음 |
| `--vv` | 매우 자세한 디버깅 정보 출력 |
| `--test` | 실제 설치하지 않고 설치 가능 여부만 테스트 |
| `--rebuilddb` | RPM 데이터베이스 재구축 |

### 제거 모드

| 옵션 | 설명 |
|---|---|
| `-e`, `--erase` | 패키지 제거 |
| `--nodeps` | 의존성 검사를 하지 않음 |
| `--test` | 실제 제거하지 않고 제거 가능 여부만 테스트 |
| `--allmatches` | 이름이 일치하는 모든 패키지 제거 |

### 질의 모드

질의 모드는 설치된 패키지 또는 패키지 파일에 대한 정보를 확인한다.

| 옵션 | 설명 |
|---|---|
| `-q` | 질의 모드 |
| `-i` | 패키지 정보 출력 |
| `-l` | 패키지가 설치한 파일 목록 출력 |
| `-a` | 설치된 모든 패키지 출력 |
| `-p 패키지_파일명` | 패키지 파일을 대상으로 질의 |
| `-f 파일명` | 해당 파일을 설치한 패키지 확인 |
| `-c` | 패키지의 설정 파일 목록 출력 |
| `-d` | 패키지의 문서 파일 목록 출력 |
| `-R` | 패키지의 의존성 정보 출력 |
| `--changelog` | 패키지 변경 이력 출력 |
| `--scripts` | 패키지에 포함된 스크립트 출력 |
| `--filesbypkg` | 패키지별 설치 파일 목록 출력 |
| `--queryformat` | 질의 결과의 출력 형식 지정 |

### 검증 모드

검증 모드는 설치된 패키지의 파일이 설치 당시와 동일한 상태인지 확인한다.

rpm -V [패키지명]

### 검증 코드

| 코드 | 의미 |
|---|---|
| `S` | 파일 크기(Size) 변경 |
| `M` | 파일 권한 및 모드(Mode) 변경 |
| `5` | MD5 체크섬 변경 |
| `D` | 장치(Device) 정보 변경 |
| `L` | 심볼릭 링크(Link) 변경 |
| `U` | 사용자 소유자(User) 변경 |
| `G` | 그룹 소유자(Group) 변경 |
| `T` | 수정 시간(Time) 변경 |
| `P` | 권한 관련 속성 변경 |
| `.` | 변경 없음 |
| `?` | 검증할 수 없음 |

### 검증 옵션

| 옵션 | 설명 |
|---|---|
| `-V` | 검증(Verify) |
| `-a` | 설치된 모든 패키지 검증 |

### 리빌드 모드

소스 RPM(`.src.rpm`) 패키지를 바이너리 RPM 패키지로 재빌드한다.

rpmbuild --rebuild 패키지.src.rpm

| 옵션 | 설명 |
|---|---|
| `--rebuild` | 소스 RPM을 재빌드하여 바이너리 RPM 생성 |
