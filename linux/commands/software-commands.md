## RPM

RPM(Red Hat Package Manager)은 RPM 패키지를 설치하고 관리하는 패키지 관리 도구이다.

### 기본 사용법

rpm [option] [패키지_파일명]

RPM의 주요 기능은 다음 5가지 모드로 구분한다.

| 모드 | 설명 |
|---|---|
| 설치 및 갱신 | 패키지를 설치하거나 기존 패키지를 갱신 |
| 제거 | 설치된 패키지를 삭제 |
| 질의 | 패키지의 정보 및 설치 상태 등을 확인 |
| 검증 | 설치된 패키지의 파일 상태를 검증 |
| 리빌드 | 소스 RPM(`.src.rpm`)을 바이너리 RPM으로 재빌드 |

### 설치 및 갱신 모드

| 옵션 | 설명 |
|---|---|
| `-i` | 패키지 설치 |
| `-U` | 패키지 갱신. 기존 패키지가 없으면 설치 |
| `-F` | 패키지 갱신. 기존 패키지가 설치되어 있는 경우에만 갱신 |
| `-v` | 자세한 정보 출력 |
| `-h` | 설치 진행 상황을 `#`으로 표시 |
| `--force` | 기존 파일이나 패키지가 있어도 강제로 설치 |
| `--nodeps` | 의존성 검사를 하지 않음 |
| `--vv` | 매우 자세한 디버깅 정보 출력 |
| `--test` | 실제 설치하지 않고 설치 가능 여부만 테스트 |
| `--rebuilddb` | RPM 데이터베이스 재구축 |

### 제거 모드

| 옵션 | 설명 |
|---|---|
| `-e`, `--erase` | 패키지 제거 |
| `--nodeps` | 의존성 검사를 하지 않음 |
| `--test` | 실제 제거하지 않고 제거 가능 여부만 테스트 |
| `--allmatches` | 이름이 일치하는 모든 패키지 제거 |

### 질의 모드

질의 모드는 설치된 패키지 또는 패키지 파일에 대한 정보를 확인한다.

| 옵션 | 설명 |
|---|---|
| `-q` | 질의 모드 |
| `-i` | 패키지 정보 출력 |
| `-l` | 패키지가 설치한 파일 목록 출력 |
| `-a` | 설치된 모든 패키지 출력 |
| `-p 패키지_파일명` | 패키지 파일을 대상으로 질의 |
| `-f 파일명` | 해당 파일을 설치한 패키지 확인 |
| `-c` | 패키지의 설정 파일 목록 출력 |
| `-d` | 패키지의 문서 파일 목록 출력 |
| `-R` | 패키지의 의존성 정보 출력 |
| `--changelog` | 패키지 변경 이력 출력 |
| `--scripts` | 패키지에 포함된 스크립트 출력 |
| `--filesbypkg` | 패키지별 설치 파일 목록 출력 |
| `--queryformat` | 질의 결과의 출력 형식 지정 |

### 검증 모드

검증 모드는 설치된 패키지의 파일이 설치 당시와 동일한 상태인지 확인한다.

rpm -V [패키지명]

### 검증 코드

| 코드 | 의미 |
|---|---|
| `S` | 파일 크기(Size) 변경 |
| `M` | 파일 권한 및 모드(Mode) 변경 |
| `5` | MD5 체크섬 변경 |
| `D` | 장치(Device) 정보 변경 |
| `L` | 심볼릭 링크(Link) 변경 |
| `U` | 사용자 소유자(User) 변경 |
| `G` | 그룹 소유자(Group) 변경 |
| `T` | 수정 시간(Time) 변경 |
| `P` | 권한 관련 속성 변경 |
| `.` | 변경 없음 |
| `?` | 검증할 수 없음 |

### 검증 옵션

| 옵션 | 설명 |
|---|---|
| `-V` | 검증(Verify) |
| `-a` | 설치된 모든 패키지 검증 |

### 리빌드 모드

소스 RPM(`.src.rpm`) 패키지를 바이너리 RPM 패키지로 재빌드한다.

rpmbuild --rebuild 패키지.src.rpm

| 옵션 | 설명 |
|---|---|
| `--rebuild` | 소스 RPM을 재빌드하여 바이너리 RPM 생성 |

## DNF 사용법

### 기본 사용법

dnf [option] [command] [패키지_파일명]

### 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-y`, `--assumeyes` | 모든 질문에 자동으로 `yes`로 응답 |
| `-q`, `--quiet` | 최소한의 정보만 출력 |
| `-v`, `--verbose` | 자세한 정보 출력 |
| `--enablerepo=<repoid>` | 지정한 저장소를 일시적으로 활성화 |

### 주요 명령어

| 명령어 | 설명 |
|---|---|
| `list [--항목값]` | 패키지 목록 출력 |
| `info [패키지명]` | 패키지 정보 출력 |
| `check-update` | 업데이트 가능한 패키지 확인 |
| `upgrade [패키지명]` | 패키지 업그레이드 |
| `install [패키지명]` | 패키지 설치 |
| `search [문자열...]` | 패키지 검색 |
| `remove 패키지명` | 패키지 제거 |
| `group list` | 패키지 그룹 목록 출력 |
| `group info 패키지그룹명` | 패키지 그룹 정보 출력 |
| `group upgrade 패키지그룹명` | 패키지 그룹 업그레이드 |
| `group install 패키지그룹명` | 패키지 그룹 설치 |
| `group remove 패키지그룹명` | 패키지 그룹 제거 |
| `whatprovides` | 특정 기능이나 파일을 제공하는 패키지 검색 |
| `clean [값]` | DNF 캐시 데이터 삭제 |
| `history [sub-command]` | DNF 작업 이력 확인 및 관리 |
| `repolist` | 활성화된 저장소 목록 출력 |
| `config-manager` | DNF 저장소 및 설정 관리 |

## dpkg

`dpkg`는 Debian 계열에서 `.deb` 패키지를 직접 관리하는 저수준 패키지 관리 도구이다.

### 기본 사용법

`dpkg [option] [패키지_파일명]`

### 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-i 패키지_파일명` | 패키지 설치 |
| `-R 디렉터리` | 지정한 디렉터리와 하위 디렉터리의 패키지를 재귀적으로 처리 |
| `-l [패키지명]` | 설치된 패키지 목록 출력 |
| `-L 패키지명` | 해당 패키지가 설치한 파일 목록 출력 |
| `-r 패키지명` | 패키지 제거. 설정 파일은 남김 |
| `-P 패키지명` | 패키지 및 설정 파일까지 완전히 제거 |
| `-S 파일명` | 해당 파일이 어떤 패키지에 의해 설치되었는지 확인 |
| `-C` | 설치가 정상적으로 완료되지 않은 패키지 등 문제 있는 패키지 확인 |
| `--unpack 패키지_파일명` | 패키지 파일의 압축을 해제하고 파일을 설치하지만 설정 과정은 수행하지 않음 |
| `--configure 패키지명` | 압축 해제된 패키지의 설정 작업 수행 |
| `-a` | 모든 패키지에 대해 지정한 작업 수행 |
| `-s 패키지명` | 패키지 상태 정보 출력 |

### 주요 옵션 구분

`-l`은 **설치된 패키지 목록**을 출력하고, `-L`은 **특정 패키지가 설치한 파일 목록**을 출력한다.

`-r`은 패키지를 제거하지만 설정 파일을 남기고, `-P`는 설정 파일까지 제거한다.

## apt-get

`apt-get`은 Debian 계열에서 패키지를 설치하고 관리하는 패키지 관리 도구이다.

`dpkg`와 달리 저장소를 이용하여 패키지를 다운로드하고 의존성을 해결할 수 있다.

### 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-y` | 모든 질문에 자동으로 `yes`로 응답 |
| `--purge` | 패키지 제거 시 설정 파일까지 제거 |

### 주요 명령

| 명령 | 설명 |
|---|---|
| `update` | 패키지 목록을 저장소에서 최신 정보로 갱신 |
| `upgrade` | 설치된 패키지를 최신 버전으로 업그레이드 |
| `install 패키지명` | 패키지 설치 |
| `remove 패키지명` | 패키지 제거 |
| `clean` | 다운로드한 패키지 파일 등의 캐시 삭제 |

예:

`apt-get install nginx`

→ `nginx` 패키지를 저장소에서 다운로드하여 설치한다.

## apt-cache

`apt-cache`는 APT 패키지 캐시에 저장된 패키지 정보를 조회하는 명령어이다.

### 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-h` | 도움말 출력 |
| `--help` | 도움말 출력 |

### 주요 명령

| 명령 | 설명 |
|---|---|
| `chowsrc 패키지명` | 패키지의 소스 패키지 정보를 조회 |
| `search 문자열` | 패키지 정보에서 문자열을 검색 |
| `depends 패키지명` | 해당 패키지가 의존하는 패키지 확인 |
| `rdepends 패키지명` | 해당 패키지에 의존하는 패키지 확인 |
| `show 패키지명` | 패키지 상세 정보 출력 |
| `pkgnames [문자열]` | 패키지 이름 목록 출력 |
| `policy 패키지명` | 패키지의 설치 버전 및 저장소별 후보 버전 정보 출력 |

## apt

`apt`는 Debian 계열의 패키지를 관리하기 위한 명령어로, `apt-get`과 `apt-cache`의 주요 기능을 통합하여 제공한다.

### 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-h` | 도움말 출력 |
| `--help` | 도움말 출력 |

### 주요 명령

| 명령 | 설명 |
|---|---|
| `list` | 패키지 목록 출력 |
| `search 문자열` | 패키지 검색 |
| `show 패키지명` | 패키지 상세 정보 출력 |
| `install 패키지명` | 패키지 설치 |
| `reinstall 패키지명` | 설치된 패키지를 다시 설치 |
| `remove 패키지명` | 패키지 제거 |
| `autoremove` | 더 이상 필요하지 않은 패키지 자동 제거 |
| `update` | 패키지 목록을 최신 정보로 갱신 |
| `upgrade` | 설치된 패키지를 최신 버전으로 업그레이드 |
| `full-upgrade` | 의존성 변경까지 고려하여 시스템 패키지를 업그레이드 |
