# 파일 권한 및 링크 명령어

## 1. 파일 권한 구조

### ls -l 출력 해석

```
-rwxr-xr-- 1 posein posein 1234 Jun 23 10:00 test.sh
①  ②  ③  ④  ⑤   ⑥      ⑦     ⑧        ⑨          ⑩
```

| 번호 | 내용 | 설명 |
|---|---|---|
| ① | `-` | 파일 종류. `-`=일반파일, `d`=디렉토리, `l`=심볼릭링크 |
| ② | `rwx` | 소유자(owner) 권한 |
| ③ | `r-x` | 그룹(group) 권한 |
| ④ | `r--` | 기타(others) 권한 |
| ⑤ | `1` | 하드링크 수 |
| ⑥ | `posein` | 소유자 이름 |
| ⑦ | `posein` | 소유 그룹 이름 |
| ⑧ | `1234` | 파일 크기 (바이트) |
| ⑨ | `Jun 23 10:00` | 마지막 수정 시간 |
| ⑩ | `test.sh` | 파일명 |

### rwx 의미

| 기호 | 의미 | 파일 | 디렉토리 |
|---|---|---|---|
| `r` | read | 파일 읽기 | 디렉토리 목록 조회 |
| `w` | write | 파일 쓰기/수정 | 파일 생성/삭제 |
| `x` | execute | 파일 실행 | 디렉토리 진입 (`cd`) |
| `-` | 권한 없음 | | |

### 숫자 표현 (8진수)

| 권한 | 숫자 |
|---|---|
| `r` | 4 |
| `w` | 2 |
| `x` | 1 |
| `-` | 0 |

```
rwx = 4+2+1 = 7
r-x = 4+0+1 = 5
r-- = 4+0+0 = 4
→ rwxr-xr-- = 754
```

## 2. 특수 권한

| 종류 | 숫자 | 표시 위치 | 설명 |
|---|---|---|---|
| Set-UID | 4 | 소유자 x 자리 → `s` | 실행 시 파일 소유자 권한으로 동작 |
| Set-GID | 2 | 그룹 x 자리 → `s` | 실행 시 파일 소유 그룹 권한으로 동작. 디렉토리에 설정 시 생성되는 파일의 그룹이 디렉토리 소유 그룹으로 자동 지정 |
| Sticky-Bit | 1 | others x 자리 → `t` | 공유 디렉토리에서 본인 파일만 삭제 가능 |

> x 권한 없이 특수권한만 설정되면 소문자 대신 대문자(`S`, `T`)로 표시 → 동작 안 함을 의미

```bash
chmod 4755 파일명   # Set-UID
chmod 2755 파일명   # Set-GID
chmod 1755 파일명   # Sticky-Bit
```

## 3. chmod

파일/디렉토리의 권한을 변경하는 명령어

```bash
chmod [option] mode file(s)
```

### 옵션

| 옵션 | 약어 | 설명 |
|---|---|---|
| `-R` | `--recursive` | 하위 파일까지 모두 권한 변경 |
| `-c` | `--changes` | 실제로 변경된 파일만 출력 |
| `-f` | `--silent` | 오류 메시지 무시 |
| `-v` | `--verbose` | 변경 전후 권한 정보 출력 |
| `--version` | | 버전 출력 |

### 기호 방식

| 대상 | 의미 |
|---|---|
| `u` | 소유자 |
| `g` | 그룹 |
| `o` | 기타 |
| `a` | 전체 |

| 기호 | 의미 |
|---|---|
| `+` | 권한 추가 |
| `-` | 권한 제거 |
| `=` | 권한 지정 (나머지 제거) |

```bash
chmod u+x test.sh      # 소유자에게 실행 권한 추가
chmod g-w test.sh      # 그룹에서 쓰기 권한 제거
chmod a+x test.sh      # 모든 사용자에게 실행 권한 추가
chmod 755 test.sh      # 숫자 방식
```

## 4. chown / chgrp / chmod 공통 옵션

| 옵션 | 설명 | chmod | chown | chgrp |
|---|---|---|---|---|
| `-R` | 하위 파일까지 모두 변경 | ✅ | ✅ | ✅ |
| `-c` | 실제로 변경된 파일만 출력 | ✅ | ✅ | ✅ |
| `-f` | 오류 메시지 무시 | ✅ | ✅ | ✅ |
| `-v` | 변경된 모든 파일 정보 출력 | ✅ | ✅ | ✅ |
| `--version` | 버전 출력 | ✅ | ✅ | ✅ |
| `-h` | 심볼릭 링크 자체의 소유권 변경 | ❌ | ❌ | ✅ |

### chown 예시

```bash
chown jiwon test.sh          # 소유자만 변경
chown jiwon:dev test.sh      # 소유자 + 그룹 변경
chown :dev test.sh           # 그룹만 변경 (chgrp과 동일)
```

## 5. umask

파일/디렉토리 생성 시 기본 권한에서 뺄 권한을 설정

| 구분 | 기본 권한 |
|---|---|
| 파일 | 666 |
| 디렉토리 | 777 |

```
umask 022 일 때
파일      : 666 - 022 = 644
디렉토리  : 777 - 022 = 755
```

| 옵션 | 설명 |
|---|---|
| `-S` | umask 값을 기호 방식으로 출력 |

```bash
umask        # 0022 (숫자)
umask -S     # u=rwx,g=rx,o=rx (기호)
```

> umask = "이 권한은 빼줘" 라는 금지 목록

## 6. ln

파일 링크를 생성하는 명령어

```bash
ln [option] 원본 링크명
```

| 옵션 | 약어 | 설명 |
|---|---|---|
| `-s` | `--symbolic` | 심볼릭 링크 생성 |
| `-v` | `--verbose` | 링크 생성 과정 출력 |
| `-f` | `--force` | 동일한 파일명 존재 시 덮어쓰기 |

### 하드 링크 vs 심볼릭 링크

| | 하드 링크 | 심볼릭 링크 |
|---|---|---|
| 명령어 | `ln 원본 링크명` | `ln -s 원본 링크명` |
| inode | 원본과 동일 | 별도 inode |
| 원본 삭제 시 | 파일 유지 | 링크 깨짐 |
| 다른 파티션 | 불가 | 가능 |
| 디렉토리 링크 | 불가 | 가능 |
| 개념 | 안전장치 (같은 데이터에 이름 하나 더) | 바로가기 |

### inode

파일의 실제 데이터 위치, 권한, 소유자 등 메타데이터를 저장하는 구조체

```
하드링크:
원본 test.sh  ──┐
                ├──→ inode (실제 데이터)
hard_link     ──┘

심볼릭링크:
soft_link ──→ 경로(/home/jiwon/test.sh) ──→ inode
```

### ls -il 로 확인

```bash
ls -il
# 111111 -rw-r--r-- 2 jiwon jiwon 1234 aaa.txt   ← inode 같음
# 111111 -rw-r--r-- 2 jiwon jiwon 1234 a          ← 하드링크
# 222222 -rw-r--r-- 1 jiwon jiwon 1234 bbb.txt
# 333333 lrwxrwxrwx 1 jiwon jiwon    7 b -> bbb.txt ← 심볼릭
```

> 하드링크 수가 0이 되면 파일이 완전히 삭제됨

## 7. cp

파일이나 디렉토리를 복사하는 명령어

```bash
cp 원본 복사본
cp 원본 디렉토리/
cp -r 디렉토리 복사위치    # 디렉토리 복사 시 -r 필수
```

### cp vs 하드링크

| | cp | 하드링크 |
|---|---|---|
| inode | 새로 생성 | 동일 |
| 용량 | 두 배 차지 | 그대로 |
| 원본 수정 시 | 복사본 영향 없음 | 같이 반영 |
