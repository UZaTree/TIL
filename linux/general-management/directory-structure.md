# 리눅스 디렉토리 구조

## 1. 전체 구조

리눅스는 `/` (루트 디렉토리) 를 최상위로 트리 구조로 뻗어나감

```
/ (루트 디렉토리)
├ home/
│   ├ jiwon/     ← 일반 사용자 홈 디렉토리
│   └ minsu/
├ root/          ← root 계정 홈 디렉토리 (예외적으로 /home 아래가 아님)
├ etc/           ← 시스템 설정 파일
├ bin/           ← 기본 명령어 실행 파일
├ sbin/          ← 관리자용 명령어
├ usr/           ← 사용자 프로그램, 라이브러리
├ var/           ← 가변 데이터 (로그 등)
└ tmp/           ← 임시 파일
```

---

## 2. 주요 디렉토리

| 디렉토리 | 약자 | 역할 |
|---|---|---|
| `/etc` | Editable Text Configuration | 시스템 설정 파일 모음 |
| `/bin` | Binary | 기본 명령어 실행 파일 (모든 사용자 사용 가능) |
| `/sbin` | System Binary | 관리자용 명령어 |
| `/usr` | Unix System Resources | 사용자 프로그램, 라이브러리 (User의 약자가 아님) |
| `/var` | Variable | 크기가 변하는 가변 데이터 (로그, 메일 등) |
| `/home` | - | 일반 사용자 홈 디렉토리 모음 |
| `/root` | - | root 계정의 홈 디렉토리 |
| `/tmp` | Temporary | 임시 파일 저장 |

---

## 3. 주요 디렉토리 상세

### `/etc`
시스템 설정 파일 전용 폴더

```
/etc/
  ├ passwd      ← 사용자 계정 정보
  ├ shadow      ← 암호화된 비밀번호
  ├ group       ← 그룹 정보
  ├ hostname    ← 서버 이름
  ├ hosts       ← IP-도메인 매핑
  └ skel/       ← 스켈레톤 디렉토리
```

### `/bin` vs `/usr/bin`

| | `/bin` | `/usr/bin` |
|---|---|---|
| 역할 | 부팅에 필요한 핵심 명령어 | 부팅 후 사용하는 일반 명령어 |
| 예시 | `ls`, `cp`, `mv` | `git`, `python`, `vim` |

### `/var`
크기가 계속 변하는 파일 모음

```
/var/
  ├ log/      ← 시스템 로그 파일
  ├ mail/     ← 메일 데이터
  ├ spool/    ← 프린트 대기열 등
  └ tmp/      ← 임시 파일
```

---

## 4. 홈 디렉토리

각 사용자에게 할당된 개인 폴더

- 로그인하면 자동으로 홈 디렉토리에서 시작
- 본인 홈 디렉토리 안에서는 자유롭게 파일 생성/삭제 가능
- 다른 사람의 홈 디렉토리는 기본적으로 접근 제한
- `~` 기호가 홈 디렉토리의 단축 표현

```bash
cd ~        # 홈 디렉토리로 이동
pwd         # 현재 위치 출력
echo $HOME  # 홈 디렉토리 경로 출력
```
