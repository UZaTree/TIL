# 파일 관리 명령어

## 1. pwd

```bash
pwd [option]
```

| 옵션 | 설명 |
|---|---|
| `-L` | 심볼릭 링크 경로 그대로 출력 (기본값) |
| `-P` | 실제 물리적 경로 출력 |

---

## 2. cd

```bash
cd [경로]
```

| 명령어 | 설명 |
|---|---|
| `cd home` | 현재 위치 기준 home 디렉토리로 이동 (상대경로) |
| `cd /home` | 루트 기준 /home 으로 이동 (절대경로) |
| `cd` | 홈 디렉토리로 이동 |
| `cd /` | 루트 디렉토리로 이동 |
| `cd .` | 현재 디렉토리 (그대로) |
| `cd ..` | 상위 디렉토리로 이동 |
| `cd ~` | 홈 디렉토리로 이동 |
| `cd ~사용자명` | 해당 사용자의 홈 디렉토리로 이동 |
| `cd -` | 이전 디렉토리로 이동 |

---

## 3. mkdir

```bash
mkdir [option] 디렉토리명
```

| 옵션 | 설명 |
|---|---|
| `-p` | 상위 디렉토리가 없어도 자동으로 생성 |
| `-m` | 생성 시 권한 지정 |
| `-v` | 생성 과정 출력 |

```bash
mkdir -p /home/jiwon/test/sub   # 중간 디렉토리 없어도 한번에 생성
mkdir -m 755 test               # 권한 755로 생성
```

---

## 4. rmdir

```bash
rmdir [option] 디렉토리명
```

| 옵션 | 설명 |
|---|---|
| `-p` | 디렉토리 삭제 후 비어있는 상위 디렉토리도 함께 삭제 |

> 디렉토리 안에 파일이 있으면 삭제 불가. 그럴 땐 `rm -r` 사용

## 6. ls

```bash
ls [option] [경로]
```

| 옵션 | 설명 |
|---|---|
| `-a` | 숨김 파일 포함 전체 출력 |
| `-A` | `.` 과 `..` 제외한 숨김 파일 포함 출력 |
| `-F` | 파일 종류 표시 (`/`=디렉토리, `*`=실행파일, `@`=링크) |
| `-l` | 상세 정보 출력 |
| `-d` | 디렉토리 자체 정보 출력 |
| `-t` | 수정 시간 기준으로 정렬 |
| `-u` | 접근 시간 기준으로 정렬 |
| `-i` | inode 번호 출력 |
| `-r` | 역순 정렬 |
| `-R` | 하위 디렉토리까지 재귀적으로 출력 |
| `-s` | 파일 크기(블록 단위) 출력 |
| `-S` | 파일 크기 기준으로 정렬 |
| `--color` | 파일 종류별 색상으로 출력 |
| `-1` | 한 줄에 하나씩 출력 |
| `-h` | 파일 크기를 읽기 쉬운 단위로 출력 (`-l` 과 함께 사용) |
| `-Z` | SELinux 보안 컨텍스트 출력 |

## 7. cp

```bash
cp [option] 원본 복사본
```

| 옵션 | 설명 |
|---|---|
| `-r`, `-R` | 디렉토리 재귀적으로 복사 |
| `-i` | 덮어쓰기 전 확인 질문 |
| `-f` | 강제 복사 (확인 없이 덮어쓰기) |
| `-b` | 덮어쓰기 전 백업 파일 생성 |
| `-s` | 복사 대신 심볼릭 링크 생성 |
| `-p` | 원본 파일 권한, 소유자, 시간 정보 유지 |
| `-v` | 복사 과정 출력 |
| `-d` | 심볼릭 링크 자체를 복사 |
| `-a` | `-dpR` 옵션 합친 것 (아카이브 모드) |
| `-l` | 복사 대신 하드링크 생성 |
| `-u` | 원본이 더 최신일 때만 복사 |

## 8. rm

```bash
rm [option] 파일명
```

| 옵션 | 설명 |
|---|---|
| `-i` | 삭제 전 확인 질문 |
| `-f` | 강제 삭제 (확인 없이) |
| `-r`, `-R` | 디렉토리 재귀적으로 삭제 |
| `--` | 이후에 오는 것을 파일명으로 처리 |

```bash
rm -rf /backup        # 강제로 디렉토리 통째로 삭제
rm -- -test.txt       # -test.txt 파일 삭제
```

## 9. mv

```bash

```

| 옵션 | 설명 |
|---|---|
| `-i` | 덮어쓰기 전 확인 질문 |
| `-f` | 강제 이동 (확인 없이 덮어쓰기) |
| `-b` | 덮어쓰기 전 백업 파일 생성 |
| `-v` | 이동 과정 출력 |


## 10. touch

```bash
touch [option] 파일명
```

| 옵션 | 설명 |
|---|---|
| `-a` | 접근 시간(atime)만 변경 |
| `-m` | 수정 시간(mtime)만 변경 |
| `-t` | 시간을 직접 지정 (YYYYMMDDHHMM 형식) |
| `-r` | 다른 파일의 시간 정보를 참조해서 적용 |

```bash
touch test.txt                    # 파일 생성 또는 시간 갱신
touch -t 202506231200 test.txt    # 시간 직접 지정
touch -r ref.txt test.txt         # ref.txt 시간을 test.txt에 적용
```

## 13. find

```bash
find [경로] [조건] [동작]
```

### 조건 옵션

| 옵션 | 설명 |
|---|---|
| `-name` | 파일명으로 검색 |
| `-iname` | 파일명 대소문자 구분 없이 검색 |
| `-user` | 특정 소유자의 파일 검색 |
| `-group` | 특정 그룹의 파일 검색 |
| `-uid` | 특정 UID의 파일 검색 |
| `-gid` | 특정 GID의 파일 검색 |
| `-perm` | 특정 권한의 파일 검색 |
| `-type` | 파일 종류로 검색 (`f`=파일, `d`=디렉토리, `l`=링크) |
| `-atime n` | n일 전에 접근한 파일 검색 |
| `-ctime n` | n일 전에 속성이 변경된 파일 검색 |
| `-mtime n` | n일 전에 수정된 파일 검색 |
| `-size n` | 파일 크기로 검색 |
| `-inum n` | inode 번호로 검색 |
| `-maxdepth n` | 검색할 디렉토리 깊이 제한 |
| `-empty` | 빈 파일/디렉토리 검색 |
| `-newer` | 특정 파일보다 최신 파일 검색 |
| `-cnewer` | 특정 파일보다 속성 변경이 최신인 파일 검색 |
| `-prune` | 특정 디렉토리 검색 제외 |

### 동작 옵션

| 옵션 | 설명 |
|---|---|
| `-exec` | 검색된 파일에 명령어 실행 (확인 없이) |
| `-ok` | 검색된 파일에 명령어 실행 (확인 후) |
| `-print` | 검색 결과 출력 (기본값) |
| `-fprint` | 검색 결과를 파일로 저장 |
| `-ls` | 검색 결과를 ls -l 형태로 출력 |

```bash
find / -name "*.txt"                    # 전체에서 txt 파일 검색
find /home -user jiwon                  # jiwon 소유 파일 검색
find / -perm 755                        # 권한 755인 파일 검색
find / -mtime -7                        # 7일 이내 수정된 파일
find / -name "*.log" -exec rm {} \;    # 검색 후 삭제
find / -name "*.txt" 2>/dev/null       # 오류 메시지 숨기기
```

## 19. grep

```bash
grep [option] 패턴 파일명
```

| 옵션 | 설명 |
|---|---|
| `-b` | 검색 결과 앞에 블록 번호 출력 |
| `-c` | 검색된 줄 수만 출력 |
| `-h` | 파일명 출력 안 함 |
| `-i` | 대소문자 구분 없이 검색 |
| `-n` | 줄 번호 포함 출력 |
| `-v` | 패턴이 없는 줄만 출력 (반전) |
| `-w` | 단어 단위로 검색 |
| `-x` | 줄 전체가 패턴과 일치하는 것만 출력 |
| `-l` | 패턴이 있는 파일명만 출력 |
| `-r` | 하위 디렉토리 재귀적으로 검색 |
| `-o` | 패턴과 일치하는 부분만 출력 |
| `-E` | 확장 정규표현식 사용 (egrep 과 동일) |
| `-F` | 정규표현식 없이 문자열 그대로 검색 (fgrep 과 동일) |
| `-A 숫자` | 패턴 매칭 줄 이후 n줄도 함께 출력 |
| `--color=auto` | 검색 결과 색상으로 표시 |

### 정규 표현식

| 표현식 | 설명 |
|---|---|
| `.` | 임의의 문자 1개 |
| `.*` | 임의의 문자 0개 이상 |
| `a*` | a가 0개 이상 반복 |
| `[abc]` | a, b, c 중 하나 |
| `[0-9]` | 0~9 숫자 중 하나 |
| `[^1-3]` | 1~3을 제외한 문자 |
| `'^pattern'` | 줄의 시작이 pattern |
| `'pattern$'` | 줄의 끝이 pattern |
| `'₩<pattern'` | pattern으로 시작하는 단어 |
| `'pattern₩>'` | pattern으로 끝나는 단어 |

## 23. split

```bash
split [option] 파일명 [prefix]
```

| 옵션 | 설명 |
|---|---|
| `-b` | 파일 크기(바이트) 단위로 분할 |
| `-l` | 줄 수 단위로 분할 |

```bash
split -b 100M test.txt backup_    # 100MB 단위로 분할, prefix 지정
split -l 1000 test.txt            # 1000줄 단위로 분할
```

> 분할된 파일은 기본적으로 `xaa`, `xab`, `xac` ... 순으로 생성

## 24. tr

```bash
tr [option] 문자1 문자2
```

| 옵션 | 설명 |
|---|---|

## 25. sed

```bash
sed [option] 'command' 파일명
```

### 옵션

| 옵션 | 설명 |
|---|---|
| `-n` | 자동 출력 억제 (`p` 명령어와 함께 사용) |
| `-f 파일명` | 스크립트 파일에서 명령어 읽기 |
| `-i 표현식` | 파일 직접 수정 |

### 주요 명령어

| 명령어 | 설명 |
|---|---|
| `'n'a\ text` | n번째 줄 다음에 text 추가 |
| `'n'd` | n번째 줄 삭제 |
| `'n'i\ text` | n번째 줄 앞에 text 삽입 |
| `p` | 출력 (`-n` 과 함께 사용) |
| `q` | 종료 |
| `r 파일명` | 파일 내용 읽어서 출력에 추가 |
| `s/string1/string2/` | string1을 string2로 첫 번째만 치환 |
| `s/string1/string2/g` | string1을 string2로 전체 치환 |

```bash
sed '3d' test.txt                    # 3번째 줄 삭제
sed 's/hello/world/g' test.txt       # 전체 hello를 world로 치환
sed -i 's/hello/world/g' test.txt    # 파일 직접 수정
```

## 26. awk

```bash
awk [option] 'pattern{action}' 파일명
```

### 옵션

| 옵션 | 설명 |
|---|---|
| `-F 필드구분자` | 필드 구분자 지정 (기본값: 공백) |
| `-f 파일명` | awk 스크립트 파일에서 명령어 읽기 |

### pattern

| 패턴 | 설명 |
|---|---|
| `BEGIN` | 파일 처리 시작 전에 실행 |
| `END` | 파일 처리 끝난 후에 실행 |
| `/문자열/` | 해당 문자열이 포함된 줄에만 실행 |

### action

| 액션 | 설명 |
|---|---|
| `print` | 출력 |
| `$1, $2 ...` | 각 필드 값 |
| `NF` | 전체 필드 수 |
| `NR` | 현재 줄 번호 |

```bash
awk '{print $1}' test.txt              # 첫 번째 필드 출력
awk -F: '{print $1}' /etc/passwd       # : 구분자로 첫 번째 필드 출력
awk '/root/{print}' /etc/passwd        # root 포함된 줄 출력
awk 'BEGIN{print "start"} {print} END{print "end"}' test.txt
```
