# 사용자/그룹 관리 명령어

## 1. useradd

### 기본 구조
```bash
useradd [option] 사용자명
```

### 옵션 정리

| 옵션 | 약어 | 설명 |
|---|---|---|
| `-p` | `--password` | 암호화된 값으로 비밀번호 지정 |
| `-d` | `--home-dir` | 홈 디렉토리 경로 직접 지정 (기본값: /home/사용자명) |
| `-g` | `--gid` | 기본 그룹 지정 (그룹명 또는 GID) |
| `-b` | `--base-dir` | 홈 디렉토리의 기준 디렉토리 지정 |
| `-G` | `--groups` | 보조 그룹 지정 (여러 개면 쉼표로 구분) |
| `-c` | `--comment` | 사용자 설명(코멘트) 지정. `/etc/passwd`의 GECOS 필드에 저장됨 |
| `-s` | `--shell` | 로그인 셸 지정 (기본값: /bin/bash) |
| `-D` | `--defaults` | useradd 기본값 확인 또는 변경 |
| `-m` | `--create-home` | 홈 디렉토리가 없으면 자동 생성 |
| `-k` | `--skel` | 홈 디렉토리 생성 시 복사할 스켈레톤 디렉토리 지정 (`-m`과 함께 사용) |
| `-f` | `--inactive` | 암호 만료 후 유예기간(일). -1이면 비활성화 안 함 |
| `-e` | `--expiredate` | 계정 만료일 지정 (YYYY-MM-DD 형식) |
| `-u` | `--uid` | UID 직접 지정 |
| `-h` | `--help` | 도움말 출력 |

> `-g` (기본 그룹, 소문자) vs `-G` (보조 그룹, 대문자) 혼동 주의

### 실행 시 영향받는 파일

```
useradd -m jiwon 실행
      │
      ├→ /etc/passwd  : 사용자 기본 정보 추가
      ├→ /etc/shadow  : 암호화된 비밀번호 정보 추가
      ├→ /etc/group   : 기본 그룹 정보 추가
      └→ /home/jiwon/ : 홈 디렉토리 생성 + /etc/skel 내용 복사
```

### 사용 예시

```bash
useradd -m -s /bin/bash -c "linux master" jiwon
```

## 2. usermod

기존 사용자 계정 정보를 수정하는 명령어

### 기본 구조
```bash
usermod [option] 사용자명
```

### 옵션 정리

| 옵션 | 약어 | 설명 |
|---|---|---|
| `-d` | `--home` | 홈 디렉토리 변경 |
| `-m` | `--move-home` | 홈 디렉토리 변경 시 기존 파일도 이동 (`-d`와 함께 사용) |
| `-g` | `--gid` | 기본 그룹 변경 |
| `-G` | `--groups` | 보조 그룹 변경 (기존 그룹 교체) |
| `-G -a` | `--groups --append` | 보조 그룹 추가 (기존 그룹 유지) |
| `-s` | `--shell` | 로그인 셸 변경 |
| `-c` | `--comment` | 코멘트 변경 |
| `-u` | `--uid` | UID 변경 |
| `-e` | `--expiredate` | 계정 만료일 변경 |
| `-f` | `--inactive` | 유예기간 변경 |
| `-l` | `--login` | 사용자명 변경 |
| `-L` | `--lock` | 계정 잠금 |
| `-U` | `--unlock` | 계정 잠금 해제 |

> `-G` 만 쓰면 기존 보조 그룹 교체, `-G -a` 같이 써야 기존 유지하면서 추가

## 3. userdel

사용자 계정을 삭제하는 명령어

### 기본 구조
```bash
userdel [option] 사용자명
```

### 옵션 정리

| 옵션 | 약어 | 설명 |
|---|---|---|
| `-r` | `--remove` | 홈 디렉토리와 메일 스풀까지 함께 삭제 |

## 4. chpasswd

여러 사용자의 비밀번호를 한번에 변경하는 명령어

| 옵션 | 약어 | 설명 |
|---|---|---|
| `-S` | `--SHA-512` | SHA-512 암호화 방식 사용 |
| `-l` | `--login` | 계정 잠금 |
| `-u` | `--unlock` | 계정 잠금 해제 |
| `-d` | `--delete` | 비밀번호 삭제 |
| `-n` | `--mindays` | 비밀번호 최소 사용 기간 |
| `-x` | `--maxdays` | 비밀번호 최대 사용 기간 |
| `-w` | `--warndays` | 비밀번호 만료 경고 기간 |
| `-i` | `--inactive` | 유예기간 설정 |
| `-e` | `--expiredate` | 계정 만료일 설정 |

## 5. groupadd

그룹을 생성하는 명령어

```bash
groupadd [option] 그룹명
```

| 옵션 | 약어 | 설명 |
|---|---|---|
| `-g` | `--gid` | GID 직접 지정 |
| `-r` | `--system` | 시스템 그룹 생성 (GID 999 이하) |

---

## 6. groupmod

그룹 정보를 수정하는 명령어

```bash
groupmod [option] 그룹명
```

| 옵션 | 약어 | 설명 |
|---|---|---|
| `-n` | `--new-name` | 그룹명 변경 |
| `-g` | `--gid` | GID 변경 |

---

## 7. groupdel

그룹을 삭제하는 명령어

```bash
groupdel 그룹명
```

> 기본 그룹으로 지정된 사용자가 있으면 삭제 불가

## 8. gpasswd

그룹 암호 및 멤버를 관리하는 명령어

```bash
gpasswd [option] 그룹명
```

| 옵션 | 약어 | 설명 |
|---|---|---|
| `-A` | `--administrators` | 그룹 관리자 지정 |
| `-a` | `--add` | 그룹에 멤버 추가 |
| `-d` | `--delete` | 그룹에서 멤버 삭제 |
| `-r` | `--remove-password` | 그룹 암호 삭제 |
| `-R` | `--restrict` | 그룹 암호 비활성화 |
| `-m` | `--members` | 그룹 멤버 목록 설정 (기존 멤버 교체) |

> `-r` 과 `-R` 의 차이: `-r` 은 암호 삭제, `-R` 은 암호 비활성화. 결과적으로 둘 다 외부 사람의 newgrp 전환을 막음

---

## 9. newgrp

현재 세션에서 1차 그룹을 임시로 전환하는 명령어

```bash
newgrp 그룹명
```

- 로그아웃하면 원래 1차 그룹으로 돌아옴
- 그룹 멤버만 사용 가능
- 그룹 암호가 설정된 경우 외부 사람도 암호 입력 시 전환 가능하나 `-r`, `-R` 로 차단 가능
