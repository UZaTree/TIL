# 사용자 정보 확인 명령어

## 공통 옵션 의미

| 옵션 | 의미 | 연상 |
|---|---|---|
| `-u` | UID 지정 | **u**id |
| `-g` | 기본 그룹 지정/변경 | **g**id |
| `-G` | 보조 그룹 지정/변경 | **G**roups |
| `-a` | 추가 (교체 아님) | **a**ppend |
| `-d` | 홈 디렉토리 경로 직접 지정 | **d**irectory |
| `-m` | 홈 디렉토리 자동 생성 | **m**ake |
| `-b` | 홈 디렉토리 기준 경로 지정 | **b**ase |
| `-k` | 스켈레톤 디렉토리 지정 | s**k**el |
| `-s` | 로그인 셸 지정 | **s**hell |
| `-c` | 코멘트 지정 | **c**omment |
| `-p` | 비밀번호 지정 | **p**assword |
| `-e` | 계정 만료일 지정 | **e**xpire |
| `-f` | 유예기간 지정 | inactive |
| `-l` | 사용자명 변경 | **l**ogin |
| `-L` | 계정 잠금 | **L**ock |
| `-U` | 계정 잠금 해제 | **U**nlock |
| `-n` | 줄 수 지정 | **n**umber |
| `-r` | 재귀적 적용 | **r**ecursive |
| `-i` | 대소문자 무시 | **i**gnore |
| `-v` | 반전 (해당 조건 제외하고 출력) | in**v**ert |

## 1. who

현재 로그인한 사용자 정보를 출력하는 명령어

```bash
who [option]
```

| 옵션 | 약어 | 설명 |
|---|---|---|
| `-b` | `--boot` | 마지막 부팅 시간 출력 |
| `-d` | `--dead` | 죽은 프로세스 출력 |
| `-H` | `--heading` | 출력 결과 상단에 헤더(컬럼명) 표시 |
| `-l` | `--login` | 로그인 대기 중인 터미널 출력 |
| `-p` | `--process` | init으로 실행된 프로세스 출력 |
| `-r` | `--runlevel` | 현재 런레벨 출력 |
| `-t` | `--time` | 마지막 시스템 시간 변경 출력 |
| `-T` | `--mesg` | 사용자의 메시지 수신 가능 여부 출력 (+/-) |
| `-u` | `--users` | 현재 로그인한 사용자 목록 출력 |
| `-m` | | 현재 사용자 정보만 출력 (`who am i` 와 동일) |
| `-a` | `--all` | 모든 정보 출력 |

### 런레벨 (Runlevel)

| 런레벨 | 의미 |
|---|---|
| 0 | 시스템 종료 |
| 1 | 단일 사용자 모드 (복구용, 네트워크 없음) |
| 2 | 다중 사용자 모드 (네트워크 없음) |
| 3 | 다중 사용자 모드 (네트워크 있음, GUI 없음) |
| 4 | 사용자 정의 |
| 5 | 다중 사용자 모드 (네트워크 있음, GUI 있음) |
| 6 | 재부팅 |

> 서버는 보통 런레벨 3, 데스크탑은 런레벨 5

## 2. w

현재 로그인한 사용자와 작업 중인 내용까지 출력하는 명령어

```bash
w [option]
```

| 옵션 | 약어 | 설명 |
|---|---|---|
| `-h` | `--no-header` | 헤더 출력 안 함 |
| `-s` | `--short` | 간략하게 출력 |

### who vs w

| | `who` | `w` |
|---|---|---|
| 로그인 사용자 | 출력 | 출력 |
| 작업 중인 명령어 | 출력 안 함 | 출력 |
| 시스템 부하 | 출력 안 함 | 출력 |


## 4. logname

처음 로그인한 계정을 출력

```bash
logname
```

### whoami vs logname

| 명령어 | 설명 |
|---|---|
| `whoami` | 현재 실제로 사용 중인 계정 출력 |
| `logname` | 처음 로그인한 계정 출력 |

> `su` 로 계정 전환 시 차이가 남. `whoami` 는 전환된 계정, `logname` 은 원래 로그인 계정

## 5. id

현재 사용자의 UID, GID, 그룹 정보를 출력

```bash
id [option] [사용자명]
```

| 옵션 | 약어 | 설명 |
|---|---|---|
| `-g` | `--group` | 기본 그룹 GID만 출력 |
| `-G` | `--groups` | 속한 모든 그룹 GID 출력 |
| `-u` | `--user` | UID만 출력 |
| `-n` | `--name` | 숫자 대신 이름으로 출력 (`-g`, `-G`, `-u` 와 함께 사용) |

```bash
id -un    # UID 이름으로 출력 (whoami 와 동일)
id -Gn    # 모든 그룹 이름으로 출력
```

---

## 6. groups

현재 사용자가 속한 그룹 목록 출력

```bash
groups [사용자명]
```

> `id -Gn` 과 결과 동일

## 7. lslogins

시스템의 사용자 계정 정보를 테이블 형태로 출력

```bash
lslogins [option]
```

| 옵션 | 약어 | 설명 |
|---|---|---|
| `-G` | `--supp-groups` | 보조 그룹 정보도 함께 출력 |
| `-L` | `--last` | 마지막 로그인 정보 출력 |
| `-u` | `--user-accs` | 일반 사용자 계정만 출력 (시스템 계정 제외) |

## 8. write

로그인한 특정 사용자에게 메시지 전송

```bash
write 사용자명
```

- 메시지 입력 후 `Ctrl + D` 로 전송 종료
- 상대방이 `mesg n` 상태면 전송 불가

```bash
mesg y   # 메시지 수신 허용
mesg n   # 메시지 수신 거부
```

---

## 9. wall

로그인한 모든 사용자에게 메시지 전송

```bash
wall "메시지"
```

> `write` 는 특정 사용자 한 명, `wall` 은 전체에게 전송

---

## 10. mail

메일을 보내거나 받은 메일을 확인하는 명령어

```bash
mail [option] [사용자명]
```

| 옵션/명령 | 설명 |
|---|---|
| `-s` | 메일 제목 지정 |
| `r` | 받은 메일에 답장 |
| `d` | 메일 삭제 |
| `n` | 다음 메일 확인 |
| `q` | 종료 |

```bash
mail -s "제목" 사용자명   # 제목 포함해서 메일 보내기
```

### write vs mail

| | `write` | `mail` |
|---|---|---|
| 전송 대상 | 현재 로그인한 사용자만 | 로그인 여부 상관없음 |
| 확인 시점 | 즉시 | 나중에 로그인해서 확인 가능 |
