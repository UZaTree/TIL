# 사운드 관리 명령어

## 1. alsactl

ALSA 사운드 카드의 설정을 관리한다.

### 주요 옵션

- `-f` → 설정 파일 지정
- `-d` → 디버그 모드

### 주요 명령

- `store` → 현재 ALSA 설정 저장
- `restore` → 저장된 ALSA 설정 복원
- `init` → 사운드 카드 초기화

---

## 2. alsamixer

터미널 환경에서 사운드 카드의 볼륨 및 음향 설정을 조절하는 믹서 프로그램이다.

- 볼륨 조절
- 음소거 설정
- 사운드 카드 채널 설정

---

## 3. cdparanoia

오디오 CD의 음악 데이터를 추출하는 프로그램이다.

### 주요 옵션

- `-w` → WAV 형식으로 출력
- `-a` → 출력 파일 지정
- `-B` → 트랙을 개별 파일로 분리하여 추출
