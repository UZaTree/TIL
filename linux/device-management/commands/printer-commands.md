# 프린터 관리 명령어

프린터 관련 명령어는 전통적으로 BSD 계열과 System V 계열로 구분할 수 있다.

## 1. BSD 계열

### lpr

프린터 작업을 프린터 큐에 등록한다.

#### 주요 옵션

- `-#` → 출력 매수 지정
- `-m` → 출력 완료 후 메일 전송
- `-P` → 사용할 프린터 지정
- `-T` → 작업 제목 지정
- `-r` → 출력 후 파일 삭제
- `-l` → 필터링하지 않고 그대로 출력

---

### lpq

프린터 큐의 상태와 작업 목록을 확인한다.

#### 주요 옵션

- `-a` → 모든 프린터의 작업 표시
- `-l` → 상세 정보 표시
- `-P` → 지정한 프린터의 작업 표시

---

### lprm

프린터 큐에 있는 작업을 삭제한다.

#### 주요 옵션

- `-` → 모든 작업 삭제
- `-U` → 작업을 제출한 사용자 지정
- `-P` → 지정한 프린터의 작업 삭제

---

### lpc

LPRng 또는 BSD 계열 프린터를 제어한다.

#### 주요 명령

- `disable` → 프린터의 작업 접수 중지
- `enable` → 프린터의 작업 접수 허용
- `down` → 프린터를 사용할 수 없는 상태로 설정
- `up` → 프린터를 사용 가능한 상태로 설정
- `help` / `?` → 도움말
- `quit` / `exit` → 종료

---

## 2. System V 계열

### lp

프린터 작업을 출력 큐에 등록한다.

#### 주요 옵션

- `-d` → 사용할 기본 프린터 지정
- `-n` → 출력 매수 지정

---

### lpstat

프린터 및 프린터 작업의 상태를 확인한다.

#### 주요 옵션

- `-p` → 프린터 상태 표시
- `-t` → 전체 프린터 상태 표시
- `-a` → 프린터의 작업 수락 여부 표시

---

### cancel

프린터 큐에 등록된 작업을 취소한다.

#### 주요 옵션

- `-a` → 모든 작업 취소

---

## BSD vs System V

| 구분 | BSD 계열 | System V 계열 |
|---|---|---|
| 출력 | `lpr` | `lp` |
| 큐 확인 | `lpq` | `lpstat` |
| 작업 삭제 | `lprm` | `cancel` |
| 프린터 제어 | `lpc` | - |
