# 모듈 관리 명령어

## 1. lsmod

현재 커널에 로드되어 있는 모듈의 목록을 확인한다.

### 사용법

`lsmod`

### 주요 정보

- 현재 로드된 모듈 이름
- 모듈 크기
- 해당 모듈을 사용하고 있는 모듈 수 및 목록

---

## 2. insmod

커널에 모듈을 직접 적재한다.

### 사용법

`insmod 모듈파일`

### 특징

- 지정한 모듈 파일을 커널에 직접 적재
- 모듈의 의존성을 자동으로 처리하지 않음

---

## 3. rmmod

커널에 적재된 모듈을 제거한다.

### 사용법

`rmmod 모듈명`

### 특징

- 현재 사용 중인 모듈은 제거할 수 없음
- 다른 모듈에서 의존하고 있는 경우 제거할 수 없음

---

## 4. modprobe

커널 모듈을 적재하거나 제거한다.

### 사용법

`modprobe 모듈명`

### 특징

- 모듈의 의존성을 자동으로 처리
- 필요한 의존 모듈을 함께 적재할 수 있음
- `insmod`보다 모듈 관리에 적합

### 주요 옵션

- `-r` → 모듈 제거
- `-c` → 현재 모듈 설정 내용 출력

---

## 5. modinfo

커널 모듈의 정보를 확인한다.

### 사용법

`modinfo 모듈명`

### 확인할 수 있는 정보

- 모듈 파일 경로
- 모듈 설명
- 라이선스
- 작성자
- 모듈 버전
- 모듈 의존성

---

## 시험 포인트

- `lsmod` → 현재 로드된 모듈 확인
- `insmod` → 모듈 직접 적재
- `rmmod` → 모듈 제거
- `modprobe` → 모듈 적재 및 제거, 의존성 자동 처리
- `modprobe -r` → 모듈 제거
- `modprobe -c` → 모듈 설정 내용 출력
- `modinfo` → 모듈 정보 확인
- `insmod` → 의존성 자동 처리 ❌
- `modprobe` → 의존성 자동 처리 ⭕

# 모듈 의존성 관리 명령어

## 1. depmod

커널 모듈 간의 의존성 정보를 생성하거나 갱신한다.

모듈의 의존 관계를 분석하여 `modules.dep` 등의 의존성 정보를 생성한다.

### 사용법

`depmod`

### 주요 옵션

- `-a` → 모든 모듈을 대상으로 의존성 정보를 생성
- `-A` → 변경된 모듈이 있는 경우에만 의존성 정보를 갱신
- `-h` → 도움말 출력

### 관련 파일

`/lib/modules/커널버전/modules.dep`

`modules.dep`에는 커널 모듈 간의 의존 관계가 기록되어 있다.

### 시험 포인트

- `depmod` → 모듈 의존성 정보 생성 및 갱신
- `modules.dep` → 모듈 의존성 정보를 저장
- `depmod -a` → 모든 모듈의 의존성 정보 갱신
- `depmod -A` → 변경된 모듈이 있을 때만 갱신
- `depmod -h` → 도움말
