# RAID 관리 명령어

## mdadm

`mdadm`은 Linux에서 소프트웨어 RAID를 생성하고 관리하는 명령어이다.

### 주요 옵션

- `-C` → RAID 장치 생성
- `-l` → RAID 레벨 지정
- `-n` → RAID에 사용할 장치 개수 지정
- `-D` → RAID 장치의 상세 정보 표시
- `-S` → RAID 장치 중지
- `-Q` → RAID 장치 상태 확인
- `-f` → 디스크를 고장 상태로 지정
- `-a` → RAID 장치에 디스크 추가
- `-r` → RAID 장치에서 디스크 제거

### RAID 생성 예시

`mdadm`을 이용하여 여러 디스크를 하나의 RAID 장치로 구성할 수 있다.

주요 구성 요소:

- RAID 장치
- RAID 레벨
- 구성 디스크
- 패리티 정보
- 스페어 디스크
