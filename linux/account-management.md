# 리눅스 계정 관리

## 1. 계정 종류

### 일반 계정 vs 시스템 계정

| 구분 | 설명 | UID 범위 |
|---|---|---|
| 일반 계정 | 실제 사람이 로그인해서 사용하는 계정 | 1000 이상 |
| 시스템 계정 | 서비스/프로그램이 사용하는 전용 계정 (사람이 로그인하는 용도가 아님) | 1 ~ 999 |

- 시스템 계정 예시: `apache`, `mysql`, `nginx`, `nobody`
- 시스템 계정은 로그인 셸을 `/sbin/nologin` 으로 설정하여 로그인을 막는 것이 일반적

---

## 2. UID / GID

- **UID (User ID)**: 모든 사용자에게 부여되는 고유 번호
- **GID (Group ID)**: 그룹에 부여되는 고유 번호
- 사용자 계정 생성 시 같은 이름의 그룹이 자동으로 생성됨

| UID/GID | 의미 |
|---|---|
| 0 | root (최고 관리자) |
| 1 ~ 999 | 시스템 계정/그룹 |
| 1000 이상 | 일반 사용자 계정/그룹 |

```bash
id        # 현재 사용자의 UID, GID 전체 출력
whoami    # 현재 사용자 이름만 출력
```

---

## 3. 그룹

같은 권한을 여러 사람에게 한 번에 부여하기 위한 묶음

### 그룹 종류

| 구분 | 설명 |
|---|---|
| 기본 그룹 (Primary Group / 1차 그룹) | 계정 생성 시 자동으로 생성되는 그룹. 딱 하나만 가질 수 있음. 파일 생성 시 이 그룹 소유로 설정됨 |
| 보조 그룹 (Secondary Group) | 추가로 속할 수 있는 그룹. 여러 개 가능 |

```bash
groups    # 내가 속한 그룹 목록 출력
id        # UID, GID, 그룹 전체 확인
```

## 4. root 계정 관리 주의사항

### 4-1. 주요 개념

| 개념 | 설명 |
|---|---|
| PAM (Pluggable Authentication Module) | 리눅스의 인증 담당 모듈. root 직접 로그인 차단 등 인증 규칙 설정 |
| 텔넷 (Telnet) | 원격 접속 방식. 데이터가 암호화 없이 전송되어 보안상 위험 → 현재는 거의 사용 안 함 |
| SSH (Secure Shell) | 텔넷의 보안 버전. 데이터를 암호화하여 원격 접속하는 현재 표준 방식 |
| TMOUT | 환경변수. 설정한 시간(초) 동안 입력이 없으면 자동 로그아웃 |

### 4-2. 5가지 주의사항

1. root 이외에 UID가 0번인 계정이 있는지 점검 (UID 0 = root와 동일한 권한)
2. PAM을 이용하여 root 직접 로그인 차단. 특히 텔넷, SSH 등 원격 로그인 서비스 통제
3. 관리자도 일반 계정으로 로그인하고, root 권한이 필요할 때만 `su` 명령어 사용
4. `TMOUT` 환경변수 설정으로 장시간 로그인 방지
5. 일반 사용자에게 특정 명령어 권한만 부여할 경우 `su`보다 `sudo` 사용 권장

### 4-3. su 명령어

계정을 전환하는 명령어

| 명령어 | 설명 |
|---|---|
| `su` | root로 계정 전환. 환경변수는 이전 계정 것 유지 |
| `su -` | root로 완전 전환. 환경변수, 홈 디렉토리 모두 root 것으로 교체 (새로 로그인한 것과 동일) |
| `su - 아이디` | 해당 계정으로 완전 전환. 환경변수, 홈 디렉토리 모두 해당 계정 것으로 교체 |
| `su -c "명령어"` | 계정 전환 없이 root 권한으로 명령어 한 줄만 실행 |

> `su -l` 은 `su -` 와 동일 (`--login` 의 약어)

### 4-4. su vs sudo

| | su | sudo |
|---|---|---|
| 방식 | 계정 자체를 전환 | 특정 명령어만 root 권한으로 실행 |
| 필요한 비밀번호 | root 비밀번호 | 본인 비밀번호 |
| 권한 범위 | root 권한 전체 | 허용된 명령어만 |
| 보안 | 상대적으로 약함 | 상대적으로 강함 |

## 5. 사용자 관련 설정 파일

### /etc/passwd 구조

```
posein:x:1000:1000:System Engineer:/home/posein:/bin/bash
  │    │   │    │         │              │           └ 로그인 셸
  │    │   │    │         │              └ 홈 디렉토리
  │    │   │    │         └ 코멘트 (-c 옵션)
  │    │   │    └ GID
  │    │   └ UID
  │    └ 암호 (x = /etc/shadow에 저장됨)
  └ 사용자명
```

- 순서 고정. 콜론 6개로 구분된 7개 필드
- 빈 필드는 콜론 유지하고 값만 비워둠

### /etc/shadow 구조

```
posein:$6$암호화된값:15728:0:99999:7:2:16101:
  1          2          3   4   5  6  7   8   9
```

| 필드 | 설명 |
|---|---|
| 1 | 사용자명 |
| 2 | 암호화된 비밀번호 (`$1$`=MD5, `$5$`=SHA-256, `$6$`=SHA-512) |
| 3 | 마지막으로 비밀번호를 변경한 날 (1970년 1월 1일 기준 일수) |
| 4 | 비밀번호 최소 사용 기간 (일). 0이면 언제든 변경 가능 |
| 5 | 비밀번호 최대 사용 기간 (일). 99999면 사실상 무제한 |
| 6 | 비밀번호 만료 경고 기간 (일) |
| 7 | 비밀번호 만료 후 유예기간 (일) |
| 8 | 계정 만료일 (1970년 1월 1일 기준 일수) |
| 9 | 예약 필드 (현재 사용 안 함) |

### /etc/group 구조

```
그룹명:암호:GID:멤버목록
  1     2    3     4
```

### /etc/gshadow 구조

```
그룹명:암호:관리자:멤버목록
  1     2     3      4
```

- 그룹 관리자는 해당 그룹 멤버일 필요 없음
- root만 읽기 가능

## 6. 사용자/그룹 관련 유틸리티

| 명령어 | 설명 |
|---|---|
| `pwconv` | `/etc/passwd` 의 비밀번호를 `/etc/shadow` 로 이동 (shadow 방식 활성화) |
| `pwunconv` | `/etc/shadow` 의 비밀번호를 `/etc/passwd` 로 되돌림 (shadow 방식 비활성화) |
| `pwck` | `/etc/passwd` 와 `/etc/shadow` 무결성 검사 |

## 7. 기본값 설정 파일

### /etc/default/useradd

```bash
useradd -D          # 현재 기본값 확인
useradd -D -옵션    # 기본값 변경
```

| 항목 | 설명 |
|---|---|
| `GROUP` | 기본 그룹 GID |
| `HOME` | 홈 디렉토리 기준 경로 |
| `INACTIVE` | 비밀번호 만료 후 유예기간 |
| `EXPIRE` | 계정 만료일 |
| `SHELL` | 기본 로그인 셸 |
| `SKEL` | 스켈레톤 디렉토리 경로 |
| `CREATE_MAIL_SPOOL` | 메일 스풀 파일 생성 여부 |

### /etc/login.defs

시스템 전체 계정 정책 설정 파일

| 항목 | 설명 |
|---|---|
| `PASS_MAX_DAYS` | 비밀번호 최대 사용 기간 |
| `PASS_MIN_DAYS` | 비밀번호 최소 사용 기간 |
| `PASS_MIN_LEN` | 비밀번호 최소 길이 |
| `PASS_WARN_AGE` | 비밀번호 만료 경고 기간 |
| `UID_MIN` | 일반 사용자 UID 최솟값 |
| `UID_MAX` | 일반 사용자 UID 최댓값 |
| `GID_MIN` | 일반 그룹 GID 최솟값 |
| `GID_MAX` | 일반 그룹 GID 최댓값 |

> `/etc/default/useradd` 는 useradd 전용, `/etc/login.defs` 는 시스템 전체 계정 정책
