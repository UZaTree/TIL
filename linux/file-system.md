# 파일 시스템 관리

## 1. 디스크 장착 후 작업 순서

```
디스크 인식 여부 확인
      ↓
파티션 작업 (fdisk)
      ↓
시스템 재부팅
      ↓
파일 시스템 생성
      ↓
디렉토리(마운트 포인트) 생성
      ↓
마운트 작업
      ↓
마운트 및 용량 확인
      ↓
부팅 시 자동 마운트 되도록 /etc/fstab 에 등록
```

---

## 2. 주요 개념

### 마운트 (Mount)
디스크나 파티션을 리눅스 디렉토리에 연결하는 작업

- 리눅스는 모든 걸 디렉토리 구조로 관리
- 새 디스크를 꽂아도 디렉토리에 연결하지 않으면 사용 불가
- 마운트 포인트 = 디스크를 연결할 디렉토리

```
새 디스크 /dev/sdb1  ──마운트──→  /data 디렉토리
```

> 윈도우에서 USB 꽂으면 D드라이브로 잡히는 것과 유사

### /etc/fstab (filesystem table)
부팅 시 자동으로 마운트할 디스크 목록을 저장하는 파일

- 마운트 작업은 재부팅하면 초기화됨
- `/etc/fstab` 에 등록하면 부팅 시 자동으로 마운트

```
장치명        마운트포인트   파일시스템   옵션      덤프  검사순서
/dev/sdb1    /data         ext4        defaults   0     0
```

### fdisk (fixed disk / format disk)
디스크 파티션을 관리하는 명령어

```bash
fdisk -l        # 디스크 목록 확인
fdisk /dev/sdb  # /dev/sdb 파티션 작업
```
