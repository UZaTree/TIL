# 프로세스 관리

## /proc 파일 시스템

- `/proc`은 실제 디스크에 존재하는 파일이 아니라 커널이 실시간으로 생성하는 가상 파일 시스템(procfs)이다.
- 시스템 및 프로세스 정보를 파일 형태로 제공한다.

## /proc/PID의 구조

프로세스 하나당 `/proc/PID` 디렉터리가 생성되며, 해당 프로세스의 정보가 파일 형태로 저장된다.

| 파일 | 설명 |
|------|------|
| cmdline | 프로세스 실행 시 사용한 명령어 |
| cwd | 현재 작업 디렉터리 |
| environ | 환경 변수 |
| exe | 실행 파일의 심볼릭 링크 |
| fd | 열린 파일 디스크립터 목록 |
| maps | 메모리 맵 정보 |
| mounts | 마운트 정보 |
| root | 프로세스의 루트 디렉터리 |
| stat | 프로세스 상태 정보(숫자 형태) |
| statm | 메모리 사용량 |
| status | 프로세스 상태 정보(읽기 쉬운 형태) |

## at

지정한 시각에 작업을 한 번만 실행

### 사용법

```bash
at [option] 시간
```

### 옵션

| 옵션 | 설명 |
|------|------|
| `-q` | 작업 큐 지정 |
| `-c` | 예약된 작업 내용 출력 |
| `-d` | 예약 작업 삭제 (`atrm`과 동일) |
| `-l` | 예약 작업 목록 출력 (`atq`와 동일) |
| `-m` | 작업 완료 후 메일 발송 |
| `-f` | 파일의 내용을 작업으로 실행 |

### 관련 명령어

| 명령어 | 설명 |
|--------|------|
| `atq` | 예약된 작업 목록 출력 |
| `atrm` | 예약된 작업 삭제 |

### 사용자 접근 제어

| 파일 | 설명 |
|------|------|
| `/etc/at.allow` | 등록된 사용자만 `at` 사용 가능 |
| `/etc/at.deny` | `at.allow` 파일이 없을 경우 등록된 사용자는 `at` 사용 불가 |

## cron

예약된 작업을 주기적으로 자동 실행하는 데몬

### 시간 필드

```text
분    시   일   월    요일     실행할 명령
30   10   *    *    1-5    /home/user/backup.sh
```

### 시간 필드 상세

| 필드 | 범위 | 설명 |
|------|------|------|
| 분(Minute) | `0~59` | 실행할 분을 지정한다. |
| 시(Hour) | `0~23` | 실행할 시간을 지정한다. |
| 일(Day of Month) | `1~31` | 실행할 날짜를 지정한다. |
| 월(Month) | `1~12`, `Jan~Dec` | 실행할 월을 지정한다. |
| 요일(Day of Week) | `0~7`, `Sun~Sat` | 실행할 요일을 지정한다. (`0`, `7`은 일요일) |

### 특수문자

| 기호 | 설명 |
|------|------|
| `*` | 모든 값을 의미한다. |
| `,` | 여러 값을 지정한다. |
| `-` | 범위를 지정한다. |
| `/` | 일정 간격을 지정한다. |

## crontab

사용자의 주기적인 작업을 등록, 수정, 삭제하는 명령어

### 사용법

```bash
crontab [option]
```

### 옵션

| 옵션 | 설명 |
|------|------|
| `-l` | 등록된 작업 목록 출력 |
| `-e` | 작업 편집 |
| `-r` | 등록된 작업 삭제 |
| `-u` | 특정 사용자의 작업 관리 |
| `-i` | 삭제 전 확인 메시지 출력 |

## ps

프로세스 정보 출력

### 사용법

```bash
ps [option]
```

### 옵션

| 옵션 | 설명 |
|------|------|
| `a` | 터미널을 가진 모든 사용자의 프로세스 출력(BSD) |
| `u` | 사용자 중심 형식으로 출력(BSD) |
| `x` | 터미널이 없는 프로세스까지 출력(BSD) |
| `l` | 긴 형식으로 출력(BSD) |
| `e` | 환경 변수까지 출력(BSD) |
| `f` | 계층 구조(트리) 형식으로 출력(BSD) |
| `p` | 지정한 PID의 프로세스 출력(BSD) |
| `-A` | 모든 프로세스 출력(System V) |
| `-e` | 모든 프로세스 출력(System V) |
| `-a` | 세션 리더와 터미널이 없는 프로세스를 제외한 모든 프로세스 출력(System V) |
| `-f` | 전체 형식(Full Format)으로 출력(System V) |
| `-C 프로세스명` | 지정한 이름의 프로세스 출력 |
| `-o 값` | 출력 항목 지정 |
| `-p`, `--pid` | 지정한 PID의 프로세스 출력 |
| `-u` | 지정한 사용자의 프로세스 출력 |

### 주요 출력 항목

| 항목 | 설명 |
|------|------|
| `USER` | 프로세스 소유자 |
| `UID` | 사용자 ID |
| `PID` | 프로세스 ID |
| `%CPU` | CPU 사용률 |
| `%MEM` | 메모리 사용률 |
| `VSZ` | 가상 메모리 크기(KB) |
| `RSS` | 실제 물리 메모리 사용량(KB) |
| `TTY` | 제어 터미널 |
| `STAT` | 프로세스 상태 |
| `START` | 프로세스 시작 시간 |
| `STIME` | 프로세스 시작 시각 |
| `TIME` | 누적 CPU 사용 시간 |
| `COMMAND` | 실행 명령 |
| `C`, `CP` | CPU 사용률 |
| `F` | 프로세스 플래그 |
| `PPID` | 부모 프로세스 ID |
| `PRI` | 프로세스 우선순위 |
| `NI` | Nice 값 |

### STAT 상태 코드

| 코드 | 의미 |
|------|------|
| `R (Running)` | 실행 중 또는 실행 대기 |
| `S (Sleeping)` | 인터럽트 가능한 대기 상태 |
| `D (Disk Sleep)` | 인터럽트 불가능한 대기 상태(I/O 대기) |
| `T (Stopped)` | 작업 제어 등에 의해 중지 |
| `W (Paging)` | 페이징 상태(현재는 거의 사용되지 않음) |
| `Z (Zombie)` | 좀비 프로세스 |
| `X (Dead)` | 종료된 프로세스 |
| `<` | 높은 우선순위 |
| `N (Nice)` | 낮은 우선순위 |
| `L (Locked)` | 메모리가 잠금(Locked) 상태 |
| `s (Session Leader)` | 세션 리더 프로세스 |
| `l (Multi-threaded)` | 멀티 스레드 프로세스 |
| `+` | 포그라운드 프로세스 그룹 |
