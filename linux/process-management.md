# 프로세스 관리

## /proc 파일 시스템

- `/proc`은 실제 디스크에 존재하는 파일이 아니라 커널이 실시간으로 생성하는 가상 파일 시스템(procfs)이다.
- 시스템 및 프로세스 정보를 파일 형태로 제공한다.

## /proc/PID의 구조

프로세스 하나당 `/proc/PID` 디렉터리가 생성되며, 해당 프로세스의 정보가 파일 형태로 저장된다.

| 파일 | 설명 |
|------|------|
| cmdline | 프로세스 실행 시 사용한 명령어 |
| cwd | 현재 작업 디렉터리 |
| environ | 환경 변수 |
| exe | 실행 파일의 심볼릭 링크 |
| fd | 열린 파일 디스크립터 목록 |
| maps | 메모리 맵 정보 |
| mounts | 마운트 정보 |
| root | 프로세스의 루트 디렉터리 |
| stat | 프로세스 상태 정보(숫자 형태) |
| statm | 메모리 사용량 |
| status | 프로세스 상태 정보(읽기 쉬운 형태) |

## /proc 디렉터리의 주요 정보 파일 및 디렉터리

| 파일/디렉터리 | 설명 |

## at

지정한 시각에 작업을 한 번만 실행

### 사용법

```bash
at [option] 시간
```

### 옵션

| 옵션 | 설명 |
|------|------|
| `-q` | 작업 큐 지정 |
| `-c` | 예약된 작업 내용 출력 |
| `-d` | 예약 작업 삭제 (`atrm`과 동일) |
| `-l` | 예약 작업 목록 출력 (`atq`와 동일) |
| `-m` | 작업 완료 후 메일 발송 |
| `-f` | 파일의 내용을 작업으로 실행 |

### 관련 명령어

| 명령어 | 설명 |
|--------|------|
| `atq` | 예약된 작업 목록 출력 |
| `atrm` | 예약된 작업 삭제 |

### 사용자 접근 제어

| 파일 | 설명 |
|------|------|
| `/etc/at.allow` | 등록된 사용자만 `at` 사용 가능 |
| `/etc/at.deny` | `at.allow` 파일이 없을 경우 등록된 사용자는 `at` 사용 불가 |

## cron

예약된 작업을 주기적으로 자동 실행하는 데몬

### 시간 필드

```text
분    시   일   월    요일     실행할 명령
30   10   *    *    1-5    /home/user/backup.sh
```

### 시간 필드 상세

| 필드 | 범위 | 설명 |
|------|------|------|
| 분(Minute) | `0~59` | 실행할 분을 지정한다. |
| 시(Hour) | `0~23` | 실행할 시간을 지정한다. |
| 일(Day of Month) | `1~31` | 실행할 날짜를 지정한다. |
| 월(Month) | `1~12`, `Jan~Dec` | 실행할 월을 지정한다. |
| 요일(Day of Week) | `0~7`, `Sun~Sat` | 실행할 요일을 지정한다. (`0`, `7`은 일요일) |

### 특수문자

| 기호 | 설명 |
|------|------|
| `*` | 모든 값을 의미한다. |
| `,` | 여러 값을 지정한다. |
| `-` | 범위를 지정한다. |
| `/` | 일정 간격을 지정한다. |

## ps

프로세스 정보 출력

### BSD 계열과 System V 계열

Linux의 `ps` 명령은 BSD 계열과 System V 계열의 옵션을 모두 지원한다.

| 구분 | BSD 계열 | System V 계열 |
|------|----------|---------------|
| 옵션 형식 | `-` 없이 사용 | `-`를 붙여 사용 |
| 대표 명령 | `ps`, `ps aux`, `ps lax` | `ps -ef`, `ps -e`, `ps -f` |

> **시험 포인트**
>
> - BSD 계열 옵션은 `-` 없이 사용한다.
> - System V 계열 옵션은 `-`를 붙여 사용한다.
> - `ps aux`(BSD), `ps -ef`(System V)는 가장 자주 사용되는 조합이다.

### 사용법

```bash
ps [option]
```

### 옵션

| 옵션 | 계열 | 설명 |
|------|------|------|
| `a` | BSD | 터미널을 가진 모든 사용자의 프로세스 출력 |
| `u` | BSD | 사용자 중심 형식으로 출력 |
| `x` | BSD | 터미널이 없는 프로세스까지 출력 |
| `l` | BSD | 긴 형식(Long Format)으로 출력 |
| `e` | BSD | 환경 변수까지 출력 |
| `f` | BSD | 계층 구조(Tree) 형식으로 출력 |
| `p` | BSD | 지정한 PID의 프로세스 출력 |
| `-A` | System V | 모든 프로세스 출력 |
| `-e` | System V | 모든 프로세스 출력 |
| `-a` | System V | 세션 리더와 터미널이 없는 프로세스를 제외한 모든 프로세스 출력 |
| `-f` | System V | 전체 형식(Full Format)으로 출력 |
| `-C 프로세스명` | System V | 지정한 이름의 프로세스 출력 |
| `-o 값` | System V | 출력 항목 지정 |
| `-p`, `--pid` | System V | 지정한 PID의 프로세스 출력 |
| `-u` | System V | 지정한 사용자의 프로세스 출력 |

### 주요 출력 항목

| 항목 | 설명 |
|------|------|
| `USER` | 프로세스 소유자 |
| `UID` | 사용자 ID |
| `PID` | 프로세스 ID |
| `%CPU` | CPU 사용률 |
| `%MEM` | 메모리 사용률 |
| `VSZ` | 가상 메모리 크기(KB) |
| `RSS` | 실제 물리 메모리 사용량(KB) |
| `TTY` | 제어 터미널 |
| `STAT` | 프로세스 상태 |
| `START` | 프로세스 시작 시간 |
| `STIME` | 프로세스 시작 시각 |
| `TIME` | 누적 CPU 사용 시간 |
| `COMMAND` | 실행 명령 |
| `C`, `CP` | CPU 사용률 |
| `F` | 프로세스 플래그 |
| `PPID` | 부모 프로세스 ID |
| `PRI` | 우선순위(Priority) |
| `NI` | Nice 값 |

### STAT 상태 코드

| 코드 | 의미 |
|------|------|
| `R (Running)` | 실행 중 또는 실행 대기 |
| `S (Sleeping)` | 인터럽트 가능한 대기 상태 |
| `D (Disk Sleep)` | 인터럽트 불가능한 대기 상태(I/O 대기) |
| `T (Stopped)` | 작업 제어 등에 의해 중지 |
| `W (Paging)` | 페이징 상태(현재는 거의 사용되지 않음) |
| `Z (Zombie)` | 좀비 프로세스 |
| `X (Dead)` | 종료된 프로세스 |
| `<` | 높은 우선순위 |
| `N (Nice)` | 낮은 우선순위 |
| `L (Locked)` | 메모리가 잠긴 상태 |
| `s (Session Leader)` | 세션 리더 프로세스 |
| `l (Multi-threaded)` | 멀티 스레드 프로세스 |
| `+` | 포그라운드 프로세스 그룹 |

## top

실시간 프로세스 및 시스템 자원 사용 현황 출력

### 사용법

```bash
top [option]
```

### 옵션

| 옵션 | 설명 |
|------|------|
| `-d` | 화면 갱신 주기(초) 지정 |
| `-p` | 지정한 PID의 프로세스만 출력 |
| `-b` | 배치(Batch) 모드로 실행 |
| `-n` | 지정한 횟수만큼 화면 갱신 후 종료 |

### 주요 출력 항목

> `ps`와 중복되는 항목은 제외

| 항목 | 설명 |
|------|------|
| `PR` | 프로세스 우선순위(Priority) |
| `VIRT` | 프로세스가 사용하는 전체 가상 메모리 |
| `RES` | 실제 물리 메모리 사용량(Resident Memory) |
| `SHR` | 다른 프로세스와 공유하는 메모리의 양|
| `S` | 프로세스 상태 |

### 실행 중 명령

| 키 | 설명 |
|----|------|
| `Space` | 화면 즉시 갱신 |
| `h`, `?` | 도움말 표시 |
| `k` | 프로세스 종료(Kill) |
| `i` | Zombie, Idle 프로세스 표시/숨김 |
| `n`, `#` | 표시할 프로세스 개수 변경 |
| `q` | 종료 |
| `r` | Nice 값 변경 |
| `s` | 화면 갱신 주기 변경 |
| `F`, `f` | 출력 항목(Field) 선택 |
| `O`, `o` | 정렬 기준 선택 |
| `l` | 맨 윗줄(uptime, Load Average) 표시/숨김 |
| `m` | 메모리 정보 표시/숨김 |
| `t` | CPU 정보 표시/숨김 |
| `c` | 명령어 전체 경로 표시/숨김 |
| `M` | 메모리 사용량 기준 정렬 |
| `P` | CPU 사용량 기준 정렬(기본값) |
| `T` | CPU 사용 시간 기준 정렬 |
| `W` | 현재 설정 저장 |

## kill

프로세스에 시그널 전달 및 제어

### 사용법

```bash
kill [option] PID
kill -s SIGNAL PID
```

### 옵션

| 옵션 | 설명 |
|------|------|
| `-l` | 시그널 목록 출력 |
| `-s SIGNAL` | 지정한 시그널 전달 |

### 주요 시그널

> **SIG는 생략 가능하다.** (예: `SIGTERM` = `TERM`)

| 번호 | 시그널 | 설명 |
|------|---------|------|
| `1` | `SIGHUP` | 프로세스 재시작 또는 설정 파일 재적용 |
| `2` | `SIGINT` | 인터럽트(Ctrl + C) |
| `3` | `SIGQUIT` | 종료 후 코어 덤프 생성 |
| `9` | `SIGKILL` | 강제 종료(무시 불가) |
| `15` | `SIGTERM` | 정상 종료(기본 시그널) |
| `18` | `SIGCONT` | 중지된 프로세스 재개 |
| `19` | `SIGSTOP` | 프로세스 강제 중지(무시 불가) |
| `20` | `SIGTSTP` | 터미널에서 일시 중지(Ctrl + Z) |
